Project Summary

AgriVision AI - Smart Farming Assistant

This project recommends suitable crops by combining soil nutrients and climate indicators inside a Flask web application. The platform keeps the original prediction model intact and upgrades the experience into a professional smart farming product.

Stack retained Flask, HTML, CSS, JavaScript, Python ML model, and the existing `joblib` file.
Core prediction inputs Nitrogen, phosphorus, potassium, temperature, humidity, pH, and rainfall.
Support modules Dashboard, plant health, weather advisory, chatbot, profile, login, and register flows.
Architecture

How the platform works

1. Flask routing

Each page is served by a dedicated route with template names that now match the actual files.

2. Existing model load

The app loads `models/best_crop_model.joblib` and keeps the prediction logic focused on the original seven-feature input array.

3. Advisory presentation

Prediction output is expanded into suitable season, soil type, water requirement, growth duration, and smart farming advice.

4. Stable demos

Weather and chatbot pages remain functional without external APIs, new packages, or fake disconnected screens.
